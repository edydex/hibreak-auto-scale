# Mac setup

Use the [setup guide](docs/setup.md) for first installation. Download the complete
release ZIP and double-click **Setup-on-Mac.command**. Missing Python/ADB tools
are installed privately.

For an update without rerunning preference setup, double-click
**Install-on-Mac.command**. It uses the same dependency bootstrap and preserves
app data. See [undo](docs/undo.md) before uninstalling or removing permissions.

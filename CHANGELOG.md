# Changelog

## v1.1.1-beta.1 — first public beta

- Published HiBreak Auto Scale 1.1.1 (Android version code 12) with its existing
  signing identity and unchanged installed-phone scaling engine.
- Automatic preparation for a selected paired car, native host-density detection,
  ownership-aware restoration, private backup export and manual fallback.
- Mac/Linux/Windows setup launchers with pinned private Python/ADB downloads.
- Scoped assistant/microphone setup, optional launcher/media/Maps preferences,
  hidden status notification and verified padlock/car-selection checkpoints.
- Skipped redundant unchanged idle saves, notification posts and status redraws.
- Added public setup, undo, support boundaries, host tests and CI.

This is a beta with limited phone/head-unit coverage. See the verification guide
for exact evidence and the remaining physical-device acceptance work. No measured
whole-device CPU, frame-rate or battery-percentage gain is claimed.
